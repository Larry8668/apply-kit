# Security

Apply Kit handles personal details (name, contact info, pay, resume), so security reports are taken seriously.

## Reporting a problem

Please don't open a public issue for a security problem. Use GitHub's private reporting instead: go to the [Security tab](https://github.com/Larry8668/apply-kit/security) and choose "Report a vulnerability". Include what you found and, if you can, a page or steps that reproduce it.

Useful things to report:

- A way for a web page to read profile data it wasn't given, or to get fields filled without the user seeing them in the review panel.
- A way for anything other than the user to change stored data or the extension's behaviour.
- Anything that makes the extension send data somewhere other than the form fields the user fills.

## Supported versions

Only the latest release gets fixes. Installed copies update themselves from [`updates.json`](updates.json).
