Profile

Fills matching fields on application forms. Leave anything blank to skip it.

Work history

Most recent or most relevant first: when a form has room for only one job, the first one is used, and job slots are filled in this order.

Education

Highest or most relevant first: a form with room for one school gets the first.

Extra fields

For questions the profile doesn’t cover. When a field’s label contains one of the keywords, this value is filled in.

Saved answers

Longer answers you reuse. Similar questions on a form get these as suggestions.

Resume

Attached to resume upload fields when you fill a form. The PDF is kept on this device only, because sync storage is too small for it. Between desktop computers its name and date sync, so the other one can tell you when its copy is out of date.

Google Drive, Google Docs, Dropbox, or a direct link to a PDF. Anyone with the link must be able to view it. Firefox asks once for permission to reach that site; nothing is downloaded until you tap Download.

Applications

Every form you fill shows up here, with the company and role Apply Kit picked up from the page. Kept on this device only.

Backup & sync

Firefox Sync copies your profile between desktop computers when Add-ons is selected in its settings. Firefox for Android doesn’t sync extension data yet, so use a transfer code or a backup file to move everything to or from a phone.

Transfer code

The quickest way to a phone. Create a code here, send it to yourself (a notes app, email, or a chat with yourself), and paste it into settings on the other device. It holds your profile, extra fields and saved answers, but not your resume or applications. Without a passphrase the code isn’t encrypted, so anyone who sees it can read your details.

Set one to lock the code, then enter the same passphrase on the other device to import it. Without it, the code can’t be read. Send the passphrase separately from the code.

Backup file

The same data as a file, for keeping a copy somewhere safe.

About

Apply Kit fills job applications from your profile after you review each field. It has no server and no tracking; your details stay in Firefox.

Updates

You’re on version . Firefox installs new versions by itself. This only checks whether one is out, and only when you tap it.
